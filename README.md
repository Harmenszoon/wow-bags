# Harmenszoon's Bags

Hides the four locked bonus slots and the green unlock button in Blizzard's backpack when those slots are unavailable on your account. It works with both separate bags and the Combined Backpack in WoW Forever.

Open your bags normally. The remaining slots close up automatically, and newly unlocked slots appear when they become usable. Combined bags also respect collapsed groups when playing with a controller.

## Installation

In WowUp, select **Get Addons**, then **Install from URL**, and paste this repository's address. [Repository URL](https://github.com/Harmenszoon/wow-bags)

For manual installation, extract the `-forever.zip` release asset into `_forever_/Interface/AddOns/` so it contains `Bags/Bags.toc`. [Download the latest release](https://github.com/Harmenszoon/wow-bags/releases/latest)
